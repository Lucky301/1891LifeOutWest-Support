1. 적용 범위

이 방침은 한국어·영어를 지원하는 1891: 서부에서 살아가기 / 1891: Life Out West의 iPhone·iPad·Mac 버전과 이 지원 사이트에 적용됩니다. 앱에 별도 게임 계정이나 사용자 채팅 기능은 없습니다.

이 방침의 운영자는 SupraCore이며, 개인정보 및 지원 문의는 support@supracore.co.kr로 접수합니다.

2. 기기에 저장되는 정보

게임 진행, 플레이어가 입력한 이름, 인벤토리와 기록, 설정, 구매 권한 상태, 사진 모드 이미지는 기기에 저장되거나 기기에서 처리됩니다. 이름에 본인 실명을 사용할 필요는 없습니다. 이 정보는 게임 실행, 진행 저장, 설정 적용과 구매 권한 확인에 사용합니다.

저장은 게임 내 삭제 기능과 기기의 파일·앱 관리 기능으로 관리합니다. 사진, 복구용 사본과 운영체제 백업은 주요 저장 파일과 별도로 남을 수 있습니다. 기기 파일은 운영체제 백업에 포함될 수 있습니다.

3. Apple 서비스

iPhone·iPad에서 iCloud 저장 동기화를 켜면 저장 슬롯의 진행, 플레이어 이름이 포함될 수 있는 저장 요약, 저장 시각, 기기 종류와 일부 진행 지표가 Apple iCloud에 동기화됩니다. 설정에서 끌 수 있습니다. 끄는 것만으로 기존 사본이 삭제되지는 않으며, 게임 내 슬롯 삭제는 해당 iCloud 사본도 삭제합니다.

iPhone·iPad에서 Game Center를 사용하면 업적과 순위표 점수가 Apple에 전달됩니다. Game Center 없이도 기본 게임을 이용할 수 있습니다. Mac 판은 현재 iCloud 저장과 Game Center를 지원하지 않습니다.

정식판 구매와 구매 복원은 Apple App Store 및 Unity IAP를 통해 처리됩니다. 구매·거래 정보와 권한 상태가 이 과정에서 사용됩니다. 앱은 결제 카드 정보를 직접 입력받거나 저장하지 않습니다. Apple 계정, 결제 기록과 Apple 서비스의 정보 처리는 Apple의 정책과 계정 관리 기능을 따릅니다.

4. Unity 엔진과 구매 SDK

앱은 Unity 엔진과 Unity IAP 5.4.4를 사용합니다. 앱 자체의 광고·광고 추적 기능은 없으며 프로젝트의 Unity Analytics·Ads 서비스는 꺼져 있습니다. 이 설정만으로 모든 SDK의 정보 처리가 없다는 뜻은 아닙니다.

Unity의 IAP 5.4 이상 문서는 설치·세션 식별자, 기기 정보, 국가 및 구매 관련 정보 등의 처리를 설명합니다. 사용한 스토어·기능과 SDK 설정에 따라 처리 범위가 달라질 수 있습니다. 관련 처리는 구매 기능 제공·운영과 서비스 보안 등의 목적으로 이뤄지며 Unity의 관련 정책이 적용됩니다.

5. 사진과 공유

사진 모드 이미지는 기기에 저장됩니다. 사용자가 공유를 선택할 때만 시스템 공유 시트의 선택한 대상으로 전달됩니다. 사진 보관함 추가 권한은 이미지를 사진 보관함에 저장할 때 사용합니다. 공유를 받은 서비스의 처리에는 해당 서비스의 정책이 적용됩니다.

6. 문의와 사이트 접속

이 지원 사이트는 정적 페이지이며 자체 문의 제출 폼, 광고, 방문 분석 스크립트나 쿠키를 사용하지 않습니다. 문의 양식 복사는 브라우저에서 처리되며 사이트로 제출되지 않습니다.

언어를 선택하면 이 브라우저에 한국어 또는 영어 선택값만 저장해 다음 방문에 사용합니다. 이 기능은 사용자 식별·광고·방문 분석에 사용하지 않으며 외부 서버에 언어 선택값을 전송하지 않습니다. 페이지의 언어 전환이나 언어 선택 링크로 바꿀 수 있고, 브라우저 사이트 데이터를 지우면 저장된 선택도 삭제됩니다.

이메일 문의 시 이메일 주소, 문의 내용과 사용자가 선택해 첨부한 기기 정보·이미지를 문의 대응 목적으로 처리합니다. 문의 대응에 필요한 기간 보관하고 목적 달성 후 지체 없이 삭제합니다. 법령상 보관 의무가 있는 기록은 해당 기간 동안 별도 보관합니다.

이 사이트는 GitHub Pages로 제공됩니다. GitHub는 로그인 여부와 관계없이 보안 목적으로 방문자의 IP 주소를 기록·보관하며, 접속 정보는 GitHub 개인정보처리방침에 따라 처리됩니다.

GitHub Issues의 버그 제보는 공개 게시물입니다. GitHub 계정 정보와 게시 내용은 GitHub의 정책에 따라 처리됩니다. 이메일 주소·영수증·저장 파일 등 개인정보를 공개하지 마세요. 비공개 문의 및 공개 자료의 삭제 요청은 지원 이메일로 보내주세요. 외부 복사본과 GitHub의 기록·보관은 해당 서비스 정책의 적용을 받습니다.

7. 보관과 삭제

기기 저장 정보는 사용자가 삭제하거나 앱·운영체제의 저장 관리 기능으로 제거할 때까지 남을 수 있습니다. 구매 기록, iCloud·Game Center 정보와 외부 서비스의 로그는 해당 사업자의 정책 및 계정 관리 기능에 따라 보관됩니다.

슬롯 삭제와 iCloud 동기화 끄기는 서로 다른 기능입니다. 앱을 삭제해도 iCloud 사본, 외부에 공유한 이미지나 운영체제 백업이 자동으로 모두 삭제되는 것은 아닙니다.

8. 선택과 권리 요청

설정에서 iCloud 동기화와 언어·게임 설정을 조절하고 기기 설정에서 사진 권한을 관리할 수 있습니다. 개인정보에 관한 열람·정정·삭제 등 적용되는 권리 요청은 위 개인정보 문의처로 보내주세요. 요청 확인에 필요한 최소한의 정보만 확인합니다.

Apple 계정·결제 및 Apple 서비스의 데이터는 Apple의 관리 기능을 이용할 수 있습니다. Unity가 직접 관리하는 정보에 대해서는 Unity 정책에 안내된 요청 경로를 사용할 수 있습니다.

9. 외부 서비스와 국외 처리

Apple·Unity·호스팅 서비스를 사용하는 정보는 사용자의 거주 국가 밖에서 처리되거나 보관될 수 있습니다. 해당 사업자의 처리 지역, 보관기간과 보호조치는 각 정책을 확인하세요. 운영자는 실제 배포에 사용하는 서비스와 정보 처리 범위를 확인하여 이 방침을 갱신합니다.

10. 방침 변경

서비스나 정보 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다. 정보 처리 목적 등 중요한 변경이 있으면 필요한 안내 절차를 진행합니다.
